# Backend

This folder contains the server-side API for Acuity Invest.

## Setup

```bash
cd backend
npm install
npm run start
```

## Features
- RESTful API for insights, portfolio, market data
- JWT authentication
- Rate limiting and middleware
- Integration with Google Gemini AI and Langfuse
- SQLite database
